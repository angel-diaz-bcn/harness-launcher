# Panel de error — Historia de Usuario

## Problema

Cuando la reproducción falla, el usuario no sabe qué hacer.

## Necesidad

Como usuario,
quiero un mensaje claro y una acción para reintentar o salir.

## Resultado esperado

- Mensaje comprensible.
- Reintentar y Salir.
- Foco inicial en Reintentar.

## Fuera de alcance

Diagnóstico técnico y reporte remoto.
