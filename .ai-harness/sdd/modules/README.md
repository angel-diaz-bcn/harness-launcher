# Catálogo de Módulos Vivos (Living Specs)

Este directorio contiene las especificaciones consolidadas del sistema.
Cada archivo `.md` representa la verdad completa y actual de una capacidad o dominio del producto.

A diferencia del enfoque anterior (donde componentes y procesos estaban fragmentados en carpetas separadas), aquí cada módulo agrupa:
- Sus contratos y tipos públicos (`CT-*`).
- Sus reglas de negocio e invariantes (`BR-*`).
- Sus flujos y procesos de ciclo de vida.
- Su mapa de implementación en el código fuente.
