# Overlay de estado — Historia de Usuario

## Problema

El usuario no sabe si la película está cargando, buscando pares o con poca velocidad.

## Necesidad

Como usuario,
quiero ver un estado claro mientras espero,
para distinguir entre cargando y fallo.

## Resultado esperado

- Indicador de preparación y buffering.
- Pares, progreso y velocidad P2P.
- Avisos efímeros de ±10 s.

## Fuera de alcance

Errores y controles.
