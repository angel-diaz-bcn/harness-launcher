# User Story — CMP-27

**Como** usuario,
**quiero** consultar la calidad y el estado de la red P2P sin salir del reproductor,
**para** entender cómo se está reproduciendo el contenido.

## Criterios de aceptación

- El icono de red abre un popover discreto.
- Muestra calidad (si existe), pares, progreso y velocidad.
- Back cierra el popover y mantiene la reproducción.
- No inventa datos ausentes.
